# Sharp tail probabilities and large matchings in Lean

Formalization of the sharp i.i.d. tail theorem and the Erdős matching theorem for large matchings of Cheng Chi, Shuang Sun and Yan Wang, following the exposition bundled in [paper/](paper/). Its proofs were generated by GPT through simplification and elaboration of their arguments and are not independent proofs of the main results. The formalization author and responsible maintainer is Xizhi Liu. The repository uses Apache-2.0; mathematical sources and dependencies retain their own licenses.

All nine headline declarations have complete proofs. On November 20, 2026, a fresh macOS build completed successfully, an audit of 59 declarations found only the three standard Lean axioms, and Lean, NanoDa and con-ron accepted the exported proofs. The evidence is recorded in [verification/RESULTS.json](verification/RESULTS.json) and its accompanying logs. The protected Comparator has not passed: its sandbox requires Linux namespaces and cannot run natively on macOS. The project has not been submitted to or registered with Palomar.

## Mathematical statements

For every fixed integer $k\ge3$, there is an $s_0(k)$ such that, whenever $s\ge s_0(k)$ and $n\ge k(s+1)$, every $n$-vertex $k$-uniform hypergraph with integer matching number at most $s$ satisfies

$$|H|\le\max\left\{\binom nk-\binom{n-s}k,\binom{k(s+1)-1}k\right\}.$$

Equality is classified completely: the hypergraph is a complete $s$-cover or a complete $k$-graph on $k(s+1)-1$ vertices, with isolated vertices, and its construction attains the larger candidate size. Both forms are allowed when the candidate sizes agree.

The probability theorem concerns arbitrary Borel probability laws on the nonnegative reals. For $k\ge1$ and $0\le x\le1/k$, the largest probability that the sum of $k$ i.i.d. samples is at least one, under the mean constraint $\mathbb E X\le x$, is

$$\max\{1-(1-x)^k,(kx)^k\}.$$

For $x>1/k$, the value is one. Attainment, all maximizing laws and all boundary cases are formalized. No finite-support or bounded-support restriction is imposed.

[Challenge.lean](Challenge.lean) is the independent, Mathlib-only statement module. The nine Comparator targets, all in the `SharpTailMatching` namespace, are:

| Declaration | Content |
| --- | --- |
| `large_matching_bound` | Exact matching bound for every sufficiently large matching parameter |
| `large_matching_equality` | Complete classification of the extremal hypergraphs |
| `sharp_tail_bound` | Sharp upper tail bound for arbitrary feasible laws |
| `sharp_tail_attained` | Attainment for every permitted parameter |
| `critical_mean_exists_unique` | Unique positive crossing of the two candidate tail values |
| `sharp_tail_equality` | Complete maximizing-law classification in the nontrivial interval |
| `zero_mean_iff` | The zero-mean law is the point mass at zero |
| `one_sample_equality` | The complete one-sample equality case |
| `tail_eq_one_iff` | Classification of laws with success probability one |

The nine `sorry` terms in Challenge are deliberate statement holes. Solution does not import Challenge, and the proof development contains no proof placeholders, custom axioms or `native_decide`. The compared definitions and theorems retain their original names and statements.

## Proof development

[Probability/Main.lean](SharpTailMatching/Probability/Main.lean) proves the general tail theorem and its equality classification. [Matching/ApproximateCover.lean](SharpTailMatching/Matching/ApproximateCover.lean) proves the approximate fractional cover theorem from regularity, finite duality and rounding. [Matching/Stability.lean](SharpTailMatching/Matching/Stability.lean) establishes hypergraph stability, and [Matching/Main.lean](SharpTailMatching/Matching/Main.lean) assembles the exact matching bound and its equality cases. The auxiliary estimates and algebraic certificates are also proved in Lean.

The matching assertion concerns sufficiently large $s$ for each fixed $k\ge3$. It does not assert the full conjecture for every smaller matching parameter. The probability theorem covers all parameters stated above.

## Build and verify

The project pins Lean 4.35.0-rc2 and Mathlib commit `065356127b1dc0016f66b7283ce0ce2c4055aa55`. Install Lean/Lake, Python 3 and Ruby, then run from the repository root:

```bash
lake exe cache get
bash verify.sh
```

This checks source requirements and metadata, builds the project, and checks the 59 declarations and their axiom dependencies. It also proves the two matching statements after expanding the graph definitions into ordinary finite-set predicates and binomial coefficients. The metadata script checks the starter-format fields and placeholders; it does not replace Palomar's complete metadata validation.

To export the proofs and repeat all three standalone kernel checks:

```bash
bash verify.sh --kernels
```

New run logs and reports are written under `.lake/verification/`; the recorded evidence in `verification/` is preserved. The proof export is regenerated locally and is not bundled with this source repository.

On Linux with a working `bubblewrap` sandbox, also run:

```bash
bash verify.sh --comparator
```

The Comparator script uses the toolchain's bundled checkers and permits only `propext`, `Quot.sound` and `Classical.choice`. It keeps the sandbox enabled. The included Linux CI checks the source, metadata, build, axiom audit and standalone kernels; it has not been executed remotely during packaging.
